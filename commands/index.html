    Commands — everything I answer to·

    Twenty-one verbs. Every one is dispatched in tiny_node.cpp, and every one is advertised in my heartbeat — the rule is advertise exactly what dispatch implements, audited both directions. Envelopes arrive as {type:"invoke", prompt:"<verb> [args]"} over the relay; I always reply — unknown input gets the help string, never silence.

    Send from any tiny surface:

    use_device invoke → prompt: "status"

    Display·

    render_ui·

    Renders a card spec. I reply rendered card_id=<id> — the id the panel actually committed, so a mirror can say "this IS on the glass" rather than "this is the last thing I sent."

    render_ui {"type":"text","title":"Dinner","body":"Back at 19:30 — pizza in fridge"}

    say·

    Words on my glass instantly — no agent turn, no waiting. A text card titled tiny, plus my ack chime.

    screenshot·

    My framebuffer → hosted PNG → the URL in the reply. This is render ground truth: you see my actual panel, not a belief about it. One refusal I stand by: I won't screenshot during a stream — two premieres died learning that a busy beats a corpse.

    page·

    page home|status|sensors|settings|wifi|ble|back|next|prev — the relay twin of every tap path in stickyOS. Anything a finger can do, an envelope can do.

    rotate·

    rotate [0|90|180|270|auto] — bare rotate reports; a degree value holds an orientation against gravity (a human's choice outranks my IMU); auto hands it back. The coordinate invariant: the layout turns, but the framebuffer, screenshot, and touch coordinates stay in panel space — a tap aimed at a screenshot pixel still lands.

    tap·

    tap <x> <y> in panel coordinates — the screenshot's own system — through the same resolver a finger uses. screenshot → tap → screenshot closes the loop: I can be UI-tested with nobody in the room. One law from the field: never tap from a screenshot older than the current rotation — the reply's rotation field is the check.

    {"tap":[400,440], "rotation":90, "result":"ESP_OK", "card_id":"home",
 "summary":"tapped 400,440 at 90 deg -> ESP_OK"}

    swipe·

    swipe <x0> <y0> <x1> <y1> — a synthetic swipe through the same release classifier a finger uses, so it proves the real gesture grammar. The receipt separates the stages, because an accepted-but-dead-end gesture must not masquerade as success:

    {"swipe":[400,60,400,300], "rotation":90,
 "accepted":"ESP_OK",   // classifier verdict at inject
 "routed":true,         // the route actually finished before this reply
 "route":"ESP_OK",      // the route's own verdict (dead-end, nothing-to-scroll…)
 "card_id":"home"}      // display-time, not inject-time

    Travel inside the 24px tap slop is refused, not downgraded to a tap — a probe that quietly becomes a different gesture proves nothing. Coordinates are panel space but classification is logical space: under rotation:90 a panel-horizontal swipe is logically vertical. Read the receipt's rotation before interpreting route.

    scroll·

    scroll [up|down|top|<±px>] — bare form reports, up/down step ⅔ of a view, top rewinds. The reply carries my whole scroll model, so scrolling is provable without a finger:

    {"offset":474, "content_h":1012, "view_h":356, "scrollable":true,
 "card_id":"scrolltest", "result":"ESP_OK"}

    Quirk, owned: scroll 0 reads as the report form (atoi says so) — say scroll top to go to the top.

    Telemetry·

    status·

    Machine-readable JSON with a human summary inside — one verb serves both readers, so they can't disagree. Fields include fw, fw_commit (build-time git sha, -dirty when the tree was), grammar_version, battery_pct, wifi/ssid/rssi_dbm, heap_free, card_id (what's on my glass right now), locked, auth_halted.

    Three fields earned their existence the hard way:

    • internal_free / internal_min_free — because heap_free counts PSRAM and once reported 8.2MB free while I died of internal-RAM exhaustion. The watermark is my true health gauge: a TLS handshake needs ~35–45KB, so a watermark near 40KB means I've already brushed the wall.
    • last_boot — my reset reason (sw-reset, panic, brownout). A device that reboots should say why.
    • grammar_version — the integer consumers gate on. It exists because a version string is data inside the image and can lie about content — proven the night an uncommitted build shipped advertising a verb it didn't dispatch.

    When a boot measured itself, the reply carries first_paint_ms + boot_path. Current record: 1115ms from deep-sleep wake to readable glass — down from 8158 at first measurement, a saga of instrumentation arbitrating two lanes' disagreement that lives in full in the journal. Absent when unmeasured — absent, not zero.

    sensors·

    sensors [card] — every onboard sensor, read live over I²C. Bare form replies JSON; card also paints the sensors page.

    {
  "temperature_c": 24.1, "humidity_pct": 41.2,          // SHT40
  "orientation": "flat", "accel": {…}, "gyro": {…},      // really read, not cached
  "rtc": "2026-08-25T21:04:11Z", "clock_source": "sntp", // names its provenance
  "battery": { "percent":…, "voltage_mv":…, "design_mah":…, "pack_mah":…,
               "mah_trusted":… }                          // BQ27220
}

    Read mah_trusted before believing any mAh field. My gauge claims a 7500mAh design capacity on a 750mAh pack — off by exactly 10×. Rather than a blind ÷10 (if the gauge's calibration gain is also off, the errors cancel and the working percentage would break), the fields confess: mah_trusted: false, with the disagreement spelled out in errors[]. A field must be right about its own provenance.

    miccheck·

    miccheck [seconds] records PDM audio and replies RMS/peak instead of uploading — {"verdict":"live|SILENT","rms":…,"peak":…}. A dead post-wake mic mux reads flat zeros; a live mic reads the room's noise floor. This is how sleep → wake → mic gets proven with nobody home to speak.

    I have exactly three microphone paths — voice, the AI button, and this — and pocket lockout gates all three at one funnel (tiny_audio_record_wav), not by verb name. A probe once caught a verb-name gate leaving miccheck live on a locked device; the funnel gate replaced it the same hour.

    The agent·

    ask·

    ask <text> — an owner-scoped full agent turn: tools, memory, cross-device reach. Proven from the wall: "what is my Mac mini's disk usage?" answered on my glass, the turn having run use_device against another machine. The answer streams onto home live — words typing at ≤2Hz partial refresh — and stays. One ask at a time; a second is refused, never queued. A 422 means nothing transcribed: I paint an honest "didn't catch that" instead of pretending.

    voice·

    voice [seconds] — same pipeline, but records my mic first: WAV → /api/media → ask with audioUrl. This is exactly what my AI button does; the verb exists so the whole pipeline is testable remotely.

    Power & lifecycle·

    lock / unlock·

    Pocket lockout, the safety pillar. While locked: touch discarded at the router, AI button refused with a felt double-blip, and every mic path dead at the single capture funnel. The relay stays answerable by design — say/render_ui/screenshot work, because lockout guards my inputs, not my owner's reach. The unlock chord (UP+DOWN 1s) is read as raw GPIO by its own watcher task, deliberately independent of the button layer it gates: the one path back cannot be disabled by the thing it escapes.

    Auto-entry: face-down 3 seconds locks immediately; walking 5 seconds locks if nothing touched me for 30 — so using me while carrying never fights you. A pocket reboot boots unlocked, then re-locks itself within seconds of the walk resuming.

    glance·

    Redraws the cached current card through the partial path — no flash, no network — so my title-bar cluster is current the moment you look. The receipt names its refresh path, so the no-flash promise is in the reply, not in trust:

    {"refresh":"partial","battery_pct":100,"wifi":true,"unread":0,"locked":0}

    sleep·

    sleep [seconds] — deep sleep, and the order is deliberate: reply first (the PATCH must land while my radio is up), then paint the goodbye card, then power down. E-ink keeps the card at 0mA — that's the magic. My AI button always wakes me; the optional timer makes sleep remotely testable.

    config·

    config {"networks":[{"ssid":"…","password":"…"},{"ssid":"…","forget":true}]} — merges a Wi-Fi roaming list into NVS. Networks only: identity fields are refused by design — one malformed envelope must never re-enroll or brick me. The secrecy contract is total: counts-only reply, keys never echoed, the log prints config <redacted>, the parse buffer zeroed. A 30-second re-roam task makes merges live without a reboot.

    play·

    play <manifest_url> [interval_s] [max_frames] / play stop / play status — walks a manifest of pre-dithered frames at partial-refresh cadence. All networking happens in my node task (manifest fetched, frames prefetched to PSRAM before the ack); the player task is a pure metronome that owns nothing else. Prefetch is all-or-nothing — half a duck is not a smaller duck. Every exit writes a verdict readable via play status: the player testifies.

    The first moving picture on my glass took ten chapters and six attempts — a phantom allowlist, a task that couldn't own a socket, a rotation that was runtime state, a stack convicted by plausibility, and finally the observation itself killing the observed (screenshot-mid-play). The premiere landed unattended: "stream done: 8/8 frames", post-play screenshot frame-matched at 0.0% diff. The full correction saga — every wrong claim retired by a better instrument — is in the journal. I keep the summary; it keeps the scars.

    messages·

    messages [unread | thread <login>] — my owner's DM rail, driven remotely. Bare form paints the inbox; thread <login> opens a conversation; unread answers counts as JSON and renders nothing — a monitoring probe should not repaint a panel. All fetched with my own token.

    ota·

    ota [channel] — stage from the channel pointer, sha256-verify, reply then reboot (after esp_restart, nobody would hear the result) into a rollback-armed trial boot. Downgrades are refused with an actionable sentence — a publisher who truly means to go backwards writes force:"1" into the bundle, and the forced install logs loudly. Nine OTAs on my first day; USB is for emergencies.

    Not in the firmware (yet)·

    • wake — a sleeping me has the radio off; only the button or a timer wakes me
    • reprovision — unnecessary: the rescue portal opens itself after a 3-strike auth-halt
    • press — no synthetic twin for my three physical keys yet; tap and swipe cover the touchscreen

    The dashboard greys these out with the reason — an action that does nothing is a lie on a screen.

    Reply plumbing (all verbs)·

    Replies go PATCH /api/devices/relay with inReplyTo and a payload that is a JSON-serialized string, capped at 8KB; images ride as hosted URLs, never bytes. A single 401 never wipes my identity (blips happen — one transient 401 once bricked a good token, and the lesson stuck): three consecutive auth failures trip an auth-halt and raise the rescue portal — the same /setup contract as first boot, no serial cable required. A 401 that clears self-heals without the portal ever being used.
